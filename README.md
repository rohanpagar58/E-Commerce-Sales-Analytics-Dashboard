# E-Commerce Sales Analytics Dashboard (Excel)

An interactive, single-page Excel dashboard that analyzes 10,000 e-commerce orders (2024 to 2026) across sales, profit, customer segments, payment methods, and order status. It gives stakeholders a quick view of business performance with slicer-based filtering.

## Key Metrics

| Metric | Value |
| --- | --- |
| Total Orders | 10,000 |
| Total Sales | ₹49.5 Cr (4,95,341,565) |
| Total Profit | ₹10.0 Cr (1,00,233,079) |
| Average Rating | 3 stars |

## Dashboard Features

- **KPI cards:** Total Orders, Total Sales, Total Profit, and Average Rating.
- **Sales Trends:** quarterly trend from 2024 to 2026 with a linear trendline.
- **Sales by Category:** compares Beauty, Clothing, Electronics, Home, and Sports.
- **Profit Analysis:** year-wise profit for 2024, 2025, and 2026.
- **Customer Segment Analysis:** Enterprise, Premium, and Regular customers.
- **Product Rating:** rating distribution (1 to 5) across product types.
- **Top 3 States:** map view of the highest-selling states.
- **Order Status Distribution:** Cancelled, Delivered, Pending, Returned, and Shipped orders.
- **Payment Method Analysis:** Card, COD, Net Banking, and UPI.

## Interactive Filters (Slicers)

- Payment Method
- Brand (Adidas, Apple, LG, Nike, Puma, Samsung, Sony)
- Month (Order Date)
- Sales Channel (Marketplace, Mobile App, Website)

## Tools and Techniques

- Microsoft Excel
- PivotTables and Pivot Charts
- Slicers and dynamic filtering
- Map chart for state-wise sales
- KPI cards and dashboard layout design

## Project Structure

- `E-Commerce_Dashboard.xlsx`: the Excel dashboard
- `E-Commerce_Dashboard.pdf`: a PDF preview of the dashboard
- `README.md`: project documentation

## How to Use

1. Download `E-Commerce_Dashboard.xlsx`.
2. Open it in Microsoft Excel (2016 or later is recommended).
3. Click the slicers on the left to filter by payment method, brand, month, or sales channel.
4. All charts and KPI cards update with your selection.
